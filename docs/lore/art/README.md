# Art direction

> **Türkçe özet.** Yalnızca sahibin onayladığı görseller kullanılır. Human OS bir sağlık uygulaması olduğu için AIONIA'nın pixel-art ve oyun kuralları burada uygulanmaz (piksel yükleme ekranı yok, sprite oyun animasyonu yok). Aion, onaylı ana referanstan alınmış hareketsiz bir resimdir; animasyon ancak bu referansa uyan paftalar gelince düşünülür.

## The one rule

**Only the owner's approved art is used** (AIONIA §0: canon and visual identity are never invented; §11 and §14.1: brand and character images come only from approved, verified sources). No generated, traced or stock substitute for Aion or any AIONIA element. AI-generated art, if the owner ever approves it, passes the same art review (§3).

## Which AIONIA art rules apply

| AIONIA rule | Applies to Human OS | Note |
|---|---|---|
| §3 pixel art as the preferred art language | **No** | §11: no forced pixel art in a health app. Aion is shown as drawn in the reference. |
| §3 the same art review for AI-generated graphics | Yes | For any future art |
| §4 keep a character's identity, colours, proportions and features | **Yes** | Blue-tipped gills, blue eyes, white coat, emblem, DNA tail stay as drawn |
| §4 no faked animation by repeating frames; record sheet metadata | Yes, when animation comes | Cell size, frame count, name, pivot, frame time, loop, source file |
| §4 keep licence and source; no assets taken from another project without permission | **Yes** | `aion_wave.png` is the owner's artwork, not under an open licence. YKSMania's Aion atlases are not copied here. |
| §14.1, §14.7 no decoration without meaning; no mixing of Fragaria, AIONIA and the app's identity | **Yes** | Aion only where D-029 places it |
| §14.3 motion only as feedback; respect reduced motion | Yes | Aion is still; a future animation stops under reduced motion and when hidden |
| §18, §19 Fragaria pixel-art loading screen | **No** | Games only; §18: not required for general apps. Human OS has no branded loading screen. |
| §12, §13, §15–§17, §20 game regressions, gamepad, game HUD, control schemes | **No** | Games only |

## Future art (PROPOSAL until approved)

- An Aion animation needs reference sheets that match the current main reference (L-015). Until then the still picture stays.
- New poses, other characters or scenery need the owner's approved source first, then a decision record. None is planned.
- Any art stays within the boundary in [../README.md](../README.md): never on medical content, never as a reaction to the person's data.
