Human OS - Windows x64 portable folder, encrypted vault (D-049)

Run: double-click human_health_os.exe. Nothing to install.

portable_mode.json makes this a portable install: your records are kept only
in an encrypted vault in UserData\ beside the app, so the whole folder can be
moved, for example to a USB stick. On first start you create a passphrase and
get a recovery key: write the key down. If both are lost, nobody can recover
the data. Nothing is written before you create or unlock the vault, and
nothing is ever written in plain text.

This build does not open entries made with a development build of Human OS.
Unsigned preview: Windows SmartScreen may warn that the publisher is unknown.
Not for clinical decisions. No network access.
